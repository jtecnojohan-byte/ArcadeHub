# ArcadeHub

Primera versión del proyecto ArcadeHub: una sala arcade web adaptable a móviles y escritorio.

## Incluye
- **Snake X:** juego clásico con teclado (flechas o WASD) y controles táctiles.
- **Pixel Dash:** reto de reflejos de 15 segundos.
- **Space Tap:** minijuego de puntería arcade.
- Récords guardados localmente en el navegador.
- Interfaz adaptable a pantallas pequeñas.

## Requisitos
- Node.js 20 o superior
- npm

## Ejecutar en desarrollo
```bash
npm install
npm run dev
```

## Crear compilación web
```bash
npm run build
npm run preview
```
